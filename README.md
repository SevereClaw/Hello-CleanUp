# Hello, CleanUp.

*давай уберём лишнее.*

Небольшая утилита для свежеустановленной Windows 10/11: чистит диск от мусора и отключает телеметрию и рекламу — насовсем, но с возможностью всё откатить.

**[Скачать последнюю версию →](https://github.com/SevereClaw/Hello-CleanUp/releases/latest)**

Один `HelloCleanUp.exe`, без установки. Написан на .NET Framework 4.8, который уже есть в любой Windows 10/11, так что запускается сразу после переустановки системы. Работает на x64, 32-битной Windows 10 и Windows на ARM.

К каждому релизу приложен `HelloCleanUp.exe.sha256`: сверь его с `Get-FileHash HelloCleanUp.exe`, чтобы убедиться, что файл не подменён.

## Что умеет

### Чистка диска
| Что | По умолчанию |
|---|---|
| Временные файлы пользователя и Windows | ✓ |
| Загруженные обновления Windows (`SoftwareDistribution\Download`) | ✓ |
| Кэш оптимизации доставки | ✓ |
| Дампы памяти после сбоев | ✓ |
| Отчёты об ошибках (WER) | ✓ |
| Кэш браузеров (Chrome, Edge, Яндекс, Brave, Vivaldi, Opera, Firefox) — только кэш, без паролей и истории | |
| Кэш шейдеров (DirectX, NVIDIA, AMD) | |
| Кэш эскизов проводника | |
| Корзина | |
| Хранилище компонентов WinSxS (DISM) | |

Перед очисткой показывается, сколько места освободится. Файлы, занятые программами, пропускаются, а символические ссылки и junction-точки никогда не раскрываются, поэтому за пределы папки очистка не выйдет.

### Телеметрия и реклама
Минимальный уровень диагностических данных, службы DiagTrack и dmwappushservice, задачи сбора данных в планировщике, рекламный ID, персонализированные предложения, реклама и автоустановка «рекомендованных» приложений в Пуске, подсказки в Параметрах и после обновлений, советы на экране блокировки, реклама OneDrive/Microsoft 365 в проводнике, Bing и веб-результаты в поиске Пуска, Recall на Copilot+ PC, история действий, запросы отзывов, сбор данных рукописного и клавиатурного ввода, а также — по желанию, по умолчанию не выбраны — Copilot, «Виджеты»/«Новости и интересы» и отправка отчётов об ошибках.

Всё это — штатные параметры, групповые политики, службы и задачи Windows. **Защитник Windows, брандмауэр, SmartScreen, UAC и Центр обновления не трогаются.**

Перед применением показывается точный список того, что изменится: каждое значение реестра «было → станет», каждая служба и задача. Применяется только после подтверждения, а то, что уже настроено как надо, в список не попадает.

## Без окна: для скриптов и автоустановки
Если запустить программу с параметрами, она работает без окна: печатает ход работы в консоль, пишет журнал в `C:\ProgramData\HelloCleanUp\logs\` и возвращает код выхода.

```
start /wait HelloCleanUp.exe /tweaks /clean
```

| Параметр | Что делает |
|---|---|
| `/tweaks[:recommended\|all\|id,id…]` | применить твики (без значения — рекомендуемые) |
| `/clean[:recommended\|all\|id,id…]` | почистить диск (без значения — рекомендуемое) |
| `/revert[:all\|id,id…]` | откатить (без значения — всё из бэкапа) |
| `/dry-run` | только показать, что изменится и сколько места освободится; ничего не менять |
| `/norestorepoint` | не создавать точку восстановления перед твиками |
| `/log:путь` | свой файл журнала |
| `/list` | список id твиков и пунктов чистки |
| `/update` | скачать и установить новую версию, если она вышла (отдельно от других действий) |
| `/?` | справка |

Коды выхода: `0` — готово, `1` — были ошибки, `2` — ошибка в параметрах, `3` — не удалось создать точку восстановления, и твики не применены (добавь `/norestorepoint`, если она не нужна).

Программе нужны права администратора: из обычной консоли Windows покажет запрос UAC. `start /wait` нужен, чтобы консоль дождалась конца работы и получила код выхода. Из PowerShell: `Start-Process HelloCleanUp.exe -ArgumentList '/tweaks','/clean' -Verb RunAs -Wait -PassThru`. В `autounattend.xml` строку можно добавить в `FirstLogonCommands`: команды оттуда выполняются от имени пользователя, поэтому настройки HKCU попадут к нему.

## Откат
- Перед каждым изменением исходное значение записывается в `C:\ProgramData\HelloCleanUp\backup.txt`.
- «Откатить выбранное» на странице твиков или «Откатить всё» в журнале возвращают всё как было.
- «Откатить всё» идёт по самому файлу бэкапа, поэтому откатывается и то, что меняли прошлые версии программы.
- Исходные значения из разделов `HKCU` хранятся отдельно для каждой учётной записи.
- По умолчанию перед применением создаётся точка восстановления Windows (защита системы включается для системного диска, если была выключена).

## Хорошо бы знать
- Настройки из разделов `HKCU` применяются к пользователю, под которым запущена программа. Запускай её из своей учётной записи — если запустить под другим администратором, программа предупредит.
- При запуске программа один раз спрашивает GitHub, нет ли новой версии. О компьютере ничего не отправляется.

## Обновления
Если вышла новая версия, программа предложит обновиться (и покажет «Обновить до …» внизу слева). Согласишься — она скачает новый `HelloCleanUp.exe` из релизов этого репозитория, сверит его SHA-256 с файлом `.sha256` из того же релиза, проверит, что это действительно Hello, CleanUp. нужной версии, заменит себя и перезапустится. Если хоть что-то не сошлось, текущая версия остаётся как есть. Без твоего согласия ничего не скачивается.

Бэкап лежит отдельно от программы, поэтому после обновления откатить можно всё, что меняли прошлые версии.

В консольном режиме программа сама не обновляется, чтобы скрипты работали предсказуемо: для этого есть `HelloCleanUp.exe /update`.
- Часть изменений (Пуск, проводник) начинает работать после перезапуска проводника или перезагрузки.
- На Windows Home и Pro политика телеметрии «0» работает как уровень «Необходимые» — меньше Microsoft не разрешает.

## Сборка
```
dotnet build src/HelloCleanUp/HelloCleanUp.csproj -c Release
```
Каждый пуш и pull request собирается в GitHub Actions.

Как выпустить новую версию:
1. Поднять `<Version>` в `HelloCleanUp.csproj` и `assemblyIdentity version` в `app.manifest` (сборка упадёт, если они разойдутся).
2. Переписать `RELEASE_NOTES.md`.
3. Запушить в `main` — появится релиз `vX.Y.Z` с exe и `.sha256`.

Уже выпущенный релиз никогда не перезаписывается: пуш в `main` без новой версии просто собирается, не трогая релиз.
