## Hello, CleanUp. v1.2.0

Если стоит v1.1.0, программа сама предложит обновиться. С v1.0 — скачай **HelloCleanUp.exe** здесь и запускай его вместо старого. Рядом лежит `HelloCleanUp.exe.sha256` для проверки файла.

### Новое: удаление встроенных приложений
Новая страница **«Приложения»**: то, что Windows ставит сама, — Candy Crush и другие игры King, Новости MSN, «Советы», витрина Microsoft 365, Solitaire, Центр отзывов, Карты, Кортана, Skype, чат Teams, Clipchamp, Power Automate и др. Рекомендуемые отмечены сразу; Погода, Почта, Медиаплеер, Xbox, Связь с телефоном и подобные — по желанию. Показывается только то, что реально есть на компьютере.

- Перед удалением — список всех пакетов, удаление только после подтверждения.
- Всё записывается в бэкап: вернуть можно кнопкой «Вернуть выбранное» или «Откатить всё». Если файлов приложения в Windows уже нет, программа откроет его страницу в Microsoft Store.
- По желанию — «Не ставить их и новым пользователям» (эта часть не откатывается).
- Microsoft Store, App Installer, Безопасность Windows, Калькулятор, Фото, Камера, Блокнот, Paint, Терминал, Ножницы и системные компоненты не удаляются никогда.
- В консоли: `/apps`, `/apps:candy-crush,msn-news`, `/deprovision`, `/revert:candy-crush`; `/list` показывает, что есть на компьютере.

### Исправлено
- Сообщения об ошибках от Windows (например, при создании точки восстановления) больше не приходят в журнал нечитаемыми символами.
