## Hello, CleanUp. v1.1.0

Скачай **HelloCleanUp.exe** и запусти (попросит права администратора). Рядом лежит `HelloCleanUp.exe.sha256`: им можно проверить, что файл скачался целым и без подмены (`Get-FileHash HelloCleanUp.exe`).

Начиная с этой версии программа обновляется сама. С v1.0 нужно один раз скачать новый exe вручную и запускать его вместо старого. Бэкап из v1.0 подхватывается сам, всё, что меняла прошлая версия, по-прежнему откатывается.

### Новое
- **Предпросмотр перед применением.** Перед «Применить» открывается список всего, что изменится: значения реестра «было → станет», службы, задачи. Без подтверждения ничего не меняется.
- **Режим без окна для скриптов и автоустановки:** `start /wait HelloCleanUp.exe /tweaks /clean`. Есть `/dry-run` (только показать изменения), `/revert`, `/list`, журнал в файл и коды выхода. Подробности: `HelloCleanUp.exe /?` и README.
- **Поиск в Пуске без Bing** — только файлы и программы на компьютере, без веб-результатов (включено в «Рекомендуемое»).
- **Recall** — запрет на сохранение снимков экрана на Copilot+ PC (включено в «Рекомендуемое»).
- **Copilot** и **Новости и виджеты** на панели задач — можно отключить, по умолчанию не выбраны.
- **Автообновление.** При запуске программа проверяет, вышла ли новая версия, и предлагает обновиться. Если согласиться, она скачает новый exe, сверит SHA-256, заменит себя и перезапустится. Без согласия ничего не скачивается, при любой ошибке остаётся текущая версия. Проверка — один запрос к GitHub, о компьютере ничего не отправляется. В консоли: `HelloCleanUp.exe /update`.
- Предупреждение, если программу запустили под другой учётной записью администратора: тогда настройки Пуска и рекламы попали бы не тому пользователю.
- Работает на 32-битной Windows 10 и нативно на Windows на ARM.

### Исправлено
- «Откатить всё» возвращает **всё** из бэкапа, даже то, что меняла прошлая версия для настроек, которых в новой уже нет.
- Повреждённая строка в бэкапе больше не обнуляет весь бэкап: остальное загружается, а исходный файл сохраняется копией рядом.
- Бэкап записывается атомарно: при сбое во время записи он не пропадает.
- Если файл бэкапа не читается, программа не меняет настройки, чтобы не потерять старые исходные значения.
- Если на компьютере несколько пользователей, исходные значения каждого хранятся отдельно и откатываются правильно.
- Чистка загруженных обновлений больше не запускает службу обновлений, если та была остановлена до этого.
- Точка восстановления создавалась, но программа сообщала «не удалось создать» и предлагала отменить применение: в ответ PowerShell попадал служебный вывод индикатора прогресса. То же исправлено для очистки кэша оптимизации доставки.
